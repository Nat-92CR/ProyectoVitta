### **# Proyecto Vitta**



Vitta es un sistema de gestión nutricional desarrollado como proyecto académico del curso de Ingeniería Informática. El objetivo del sistema es permitir a los usuarios registrar alimentos, crear menús diarios y visualizar información nutricional relacionada con su consumo alimenticio.



El sistema permitirá gestionar información como:

\- Registro de usuarios

\- Registro y consulta de alimentos

\- Creación de menús diarios

\- Cálculo de información nutricional

\- Visualización de estadísticas de consumo
